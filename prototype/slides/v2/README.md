# v2 발표자료

Figma에서 내보낸 이미지를 순서대로 띄우는 껍데기다. 디자인은 Figma에 있고 여기는 넘기기·링크·인쇄만 맡는다.

v1(`../발표자료.html`)은 소스가 `.dc.html`이라 `../build.mjs`로 만들었다. v2는 디자인이 Figma에 있어 빌드 단계가 없다. 이미지를 넣으면 끝이다.

## 넣을 이미지

`images/` 에 1920×1080 PNG 열 장을 넣는다. 파일명이 순서다.

```text
00.png   표지     담당 앱 안내                                흘림
01.png   01      사용자가 아는 농협은 하나다                   10초
02.png   01-1    농협 앱은 넷이다                            10초
03.png   02·03   나눠도 됐다 / 합쳐서 풀리지 않았다             20초
04.png   04      같은 질문인데 답이 넷이다                     40초
05.png   05      라우터                                     90초
06.png   06      노린 것                                    30초
07.png   07      잃는 것                                    30초
08.png   08      얻는 것                                    30초
09.png   09      사용자가 아는 농협은 하나다                   10초
                                                          270초
```

04부터는 파일 번호와 스피커노트의 절 번호가 같다. 01-1과 02·03이 한 칸씩 당겨 쓰기 때문에 그 둘만 어긋난다.

같은 폴더에 `05-step1-empty.png` ~ `05-step4-otherapp.png` 도 둔다. 05장 네 칸에 들어갈 시연 캡처 원본이다. 껍데기는 이 넷을 읽지 않는다. Figma에서 잘라 05.png 안에 들어간다. 자를 곳은 `docs/260916_발표자료_제작요청_3차_보강.md` 05 절.

이미지 열 장은 2026-09-16에 Figma에서 2배(3840×2160)로 내보내 넣었다.

**이미지가 없어도 열린다.** 없는 자리에는 절 번호와 이름과 시간이 적힌 자리표시자가 뜬다. 이미지가 오기 전에 순서와 시간을 확인할 수 있다.

## 띄우는 법

라우터와 같은 서버에 올린다. 그래야 05장의 라우터 링크가 상대경로로 동작한다.

```bash
cd prototype
npx -y serve .
```

그러면 이렇게 잡힌다.

```text
http://localhost:3000/slides/v2/발표자료.html    슬라이드
http://localhost:3000/router/bank-app.html      라우터 앱
http://localhost:3000/router/console.html       콘솔
```

`prototype/router/` 에서만 서버를 띄우면 슬라이드가 그 밖에 있어 열리지 않는다. 한 단계 위인 `prototype/` 에서 띄운다.

다른 자리에 두고 싶으면 `발표자료.html` 안의 `ROUTER_URL` 을 절대주소로 바꾼다.

## 05장의 클릭 영역과 실패 대비

05장은 캡처 두 칸이다. 왼쪽이 콘솔, 오른쪽이 앱. **PNG는 그림이라 눌러도 아무 일이 없으므로** 껍데기가 두 칸 위에 투명한 클릭 영역을 얹는다. 왼쪽을 누르면 콘솔이, 오른쪽을 누르면 앱이 새 탭으로 열린다.

좌표는 눈대중이 아니라 Figma 05 프레임의 「캡처 자리」 노드 위치(칸1 x92 y241 852×553 · 칸2 x976)에서 계산했다. 디자인이 바뀌면 `H`로 조정 모드를 켜고 그 칸 위를 드래그하면 붙여 넣을 좌표가 뜬다.

같은 일을 하는 길이 셋이라 하나가 막혀도 된다.

```text
캡처 칸 클릭            왼쪽 콘솔 · 오른쪽 앱
오른쪽 아래 버튼 둘       콘솔 열기 · 앱 열기. 05장에서만 뜬다
키                     C 콘솔 · D 앱. 어느 장에서든
```

### 링크가 안 열리면

```text
1  눌러도 반응이 없다        준비 단계에서 미리 열어둔 콘솔·앱 탭으로 그냥 전환한다. 링크는 편의였다
2  탭이 열리는데 빈 화면     서버가 안 떠 있다. 터미널에서  cd prototype && npx -y serve .
                          (인터넷 없어도 뜬다. 캐시돼 있다. Node 가 없으면  python -m http.server 3000)
3  주소를 직접 쳐야 하면     http://localhost:3000/router/console.html  ·  /router/bank-app.html
4  콘솔은 열리는데 발행이 안 된다   새 탭에  http://localhost:3000/router/seed.html#auto
                          "넣었습니다"가 뜨면 앱 탭에서 동기화. 3단계부터 이어간다
5  그래도 안 된다           05장 캡처 두 칸을 가리키며 말로 간다. 캡처가 그 순서 그대로다. 녹화본이 있으면 녹화본
```

4번은 실패했을 때만 쓴다. 시연 전에 미리 열면 콘솔이 "바뀐 내용이 없어 발행하지 않았습니다"라고 막는다.

## 조작

```text
→ · Space · PageDown · 화면 클릭    다음 장
← · PageUp                          이전 장
Home / End                          처음 / 마지막
C                                   콘솔 열기 (새 탭)
D                                   앱 열기 (새 탭)
T                                   타이머 켜기/끄기
H                                   클릭 영역 조정 모드
Ctrl+P                              장당 한 페이지로 PDF 저장
```

- 주소창 끝에 `#5` 를 붙이면 05장에서 시작한다. 발표 중 새로고침해도 자리를 잃지 않는다
- 05장에서만 오른쪽 아래에 `콘솔 열기` `앱 열기` 버튼이 뜬다. 버튼과 캡처 칸을 눌러도 장이 넘어가지 않는다
- 타이머는 기본으로 꺼져 있다. 켜면 경과 시간과 270초를 함께 보여주고, 넘기면 색이 바뀐다
- 왼쪽 아래 장 번호와 타이머는 인쇄할 때 빠진다

## 시연 중 돌아오기

05장 시연은 슬라이드 밖에서 한다. 슬라이드를 05장에 둔 채 브라우저 탭만 바꾼다. 돌아올 때도 탭만 바꾸면 05장 그대로다.

라우터 링크는 편의이자 실패 대비다. 발표 전에 콘솔과 앱 두 탭을 미리 열어두는 것이 먼저다. 링크 하나로는 탭 하나만 열린다.

## 보내는 법

`발표자료.html` 하나만 보내면 안 된다. 이미지를 옆 폴더 `images/`에서 읽어서, 받는 쪽에는 자리표시자만 뜬다.

**`발표자료_배포.html`을 보낸다.** 이미지 열 장이 안에 들어 있어 이 파일 하나로 열린다. 폴더도 서버도 인터넷도 필요 없다. 약 1.8 MB.

```bash
cd prototype/slides/v2
node build.mjs          # images/ 열 장을 base64 로 박아 발표자료_배포.html 을 만든다
```

- 배포본은 손으로 고치지 않는다. 슬라이드가 바뀌면 `images/`를 갈고 다시 돌린다
- 받는 쪽에서는 05장의 콘솔·앱 링크가 열리지 않는다. 발표 컴퓨터의 로컬 서버를 가리키기 때문이다. 파일 머리 주석에 그렇게 적혀 있다
- 넘기기·타이머·`Ctrl+P` 인쇄는 그대로 된다

## PDF 백업

같은 파일에서 `Ctrl+P` 로 뽑는다. 장당 한 페이지, 가로 방향이다. PDF에서는 라우터 링크가 죽으므로 시연은 탭 전환으로만 한다.

## 이 폴더와 v1의 관계

```text
../발표자료.html        v1 배포본. 지우지 않는다
../build.mjs           v1 빌드 스크립트. v2에는 쓰지 않는다
../Main.dc.html        v1 표지 소스. prototype/router/tests.mjs 가 이 파일을 본다
../Learning · Measuring · Tradeoffs   질문이 오면 열어 보여주는 참고 화면
```

v1 파일은 건드리지 않는다. 검사가 `Main.dc.html` 을 읽고 있고, 참고 화면 셋은 질문 대응용으로 남겨뒀다.
