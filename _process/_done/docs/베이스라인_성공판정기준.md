# NH 앱 담당 경로 인식 설문 분석 기준

- 작성일: 2026-08-19
- 상태: 분석 기준 확정 / V2 응답 수집 중
- 문서 유형: 계속 갱신

## 분석 원칙

이 설문은 검색어 성공률을 계산하지 않는다. 정확한 상품명을 모든 응답자에게 제공한 상태에서 담당 앱을 식별하는지를 분석한다.

NHPAY가 K-패스카드를 직접 노출한다는 판단 근거는 [`NH앱4개_카드검색_as-is결과.md`](../../../docs/NH앱4개_카드검색_as-is결과.md)다.

## Q2 첫 행동 분류

| 응답 | 분류 |
|---|---|
| NHPAY를 연다 | 담당 앱 최초 식별 |
| NH스마트뱅킹·NH콕뱅크·NH올원뱅크를 연다 | 다른 앱 선택 |
| 인터넷에서 다시 찾아본다 | 담당 앱 불확실·외부 재탐색 |
| 고객센터나 주변 사람에게 물어본다 | 담당 앱 불확실·문의 |

다른 앱을 선택했더라도 기존 연결을 통해 실제 목표 화면에 도달할 수 있으므로 이를 곧바로 실제 실패로 부르지 않는다.

## 사전 확정 지표

- 담당 앱 최초 식별률 = `NHPAY 선택 수 ÷ 전체 유효 응답 수 × 100`
- 다른 앱 선택률 = `NHPAY 외 NH 앱 선택 수 ÷ 전체 유효 응답 수 × 100`
- 추가 탐색 필요 응답률 = `(인터넷 재검색 + 문의 선택 수) ÷ 전체 유효 응답 수 × 100`
- 오답 고확신률 = `다른 앱 선택 및 확신도 4~5점인 응답 수 ÷ 전체 유효 응답 수 × 100`
- 예상 외부 탐색·포기 의향률 = `(Q5 포털 검색 + 문의 + 포기) ÷ 전체 유효 응답 수 × 100`

`실제 실패율`, `실제 이탈률`, `개선률`이라는 표현은 과제 수행이나 프로토타입 비교 전에는 사용하지 않는다.

## 교차 분석

다음 조합을 우선 확인한다.

1. NHPAY 사용 경험 × 첫 행동
2. K-패스 발급·탐색 경험 × 첫 행동
3. 첫 행동 × 선택 이유
4. 첫 행동 × 확신도
5. 첫 행동 × 실패 후 예상 행동

응답자 수가 적은 집단은 백분율만 제시하지 않고 `n`을 함께 표시한다.

## 유효성 처리

- 모든 필수 문항이 완료된 응답을 유효 응답으로 본다.
- Q1에서 `사용해본 앱 없음`과 특정 앱을 동시에 선택한 경우 Q1 세그먼트 분석에서만 제외한다.
- 동일인이 중복 제출한 사실이 명확하면 최신 응답 하나만 사용한다.
- 과제 수행 테스트 이후 설문에 답한 참가자는 일반 설문 표본과 별도 표시한다.
- 서술형 응답은 개인을 식별할 수 있는 내용을 제거한 뒤 인용한다.

## 프로젝트 의사결정 연결

설문은 담당 앱 인식이 분산되어 있는지 보여주는 보조 근거다. 기능 필요성은 외부 검색을 허용한 실제 과제에서 담당 앱 식별 시간, 공식 정보 판별, 앱 복귀, 목표 화면 도달과 실패를 확인한 뒤 결정한다.

설문에서 NHPAY 최초 선택률이 낮아도 포털 검색으로 빠르고 정확하게 공식 화면에 도달한다면 새 기능의 추가 가치는 낮다. 포털 검색 후에도 재검색·오정보·앱 복귀 실패·긴 도달 시간·포기가 반복될 때만 개선 필요성을 지지한다.
