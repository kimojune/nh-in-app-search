# AI 원본 백업 — 참고 금지

이 폴더는 2026-08-22 이전까지 AI(Claude Code)가 작성한 해석·결론 버전의 원본 백업이다.

## 목적

같은 시점의 `docs/`, `PROJECT_GUIDE.md`를 사용자가 직접 다시 해석해서 쓰기로 하면서, 원본을 잃어버리지 않기 위해 남겨둔다. 실력 향상이 목적이므로, 사용자가 직접 쓴 새 버전이 이 백업과 비슷한지 다른지 비교하는 용도로만 나중에 사용자 본인이 열어본다.

## 규칙

**에이전트(Claude Code, Codex 등)는 이 폴더의 내용을 어떤 작업에서도 읽거나 참고하지 않는다.** 사용자가 명시적으로 "백업 폴더 열어봐"라고 요청하지 않는 한 접근하지 않는다. `docs/`·`PROJECT_GUIDE.md`의 "직접 작성" 빈 칸을 채우는 작업을 도울 때, 이 폴더의 기존 문장을 참고해 답을 유추하거나 재구성하지 않는다.

이 규칙은 [`_meta/PROJECT_RULES.md`](../_meta/PROJECT_RULES.md)에도 동일하게 명시되어 있다.
