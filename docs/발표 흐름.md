가설 - 사용자는 이름을 아는 상품을 어느앱에서 처리하는지 모른다.
농협앱을 사례로 왜 나눠져있는가 조사

-> 또한 관리 주체 법인이 다르고, 인앱검색 방식이 모두 달라
	 통합된 검색시스템은 만들기 어렵다.


2. 또한 테스트 결과로 60%가 포털로 이동한다.
거대한 기능이면 개발하는 리소스 대비, 기능의 필요성이 희미해진다.
-> 이미 포털이 대체하고 있기때문

그렇다면 만들면 안될까?
1. 만들어야 할 이유
농협 중앙회 입장에서 표현
개별 앱은 "우리 앱에서 못 찾으면 포털로 나간다"가 자기 회사만의 손해가 아니라 그룹 전체의 손해
"상호금융부문"처럼, 각 조합·계열사를 지도·검사하는 조직이 이미 있습니다. 크로스앱 매핑 승인 같은 기능은 완전히 새로 만드는 게 아니라 기존 조직 위에 얹는 일

2. 다른 은행으로 빠져나갈 수 있다.
네이버에서 검색시 만나는 화면
파일럿 테스트 3명 모두가 네이버 모두의카드라는 정부 정책 채널에서 만들지 않고 
네이버에서 제공하는 신용카드 관련광고에서 진행했다.
-> 회사는 이 지점부터 포털사이트에 기생하는 구조가 된다.
-> 마찬가지로 모두의카드가 K패스를 주체하고 있음에도 알지못하기때문에 진행하지 않는다.
-> 농협앱 카드사 필터는 7번째에있다.
