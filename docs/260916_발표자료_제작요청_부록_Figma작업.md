### 글꼴 결정 (2026-09-16 확정)

**IBM Plex Sans KR로 간다. Pretendard로 되돌리지 않는다.**

처음에는 Pretendard로 등록했으나 MCP 실행 환경에서 그 글꼴을 찾지 못해(`listAvailableFontsAsync` 8,927개 중 0개) 텍스트를 만들지도 고치지도 못했다. 로컬 설치 글꼴이라 편집기 화면에는 보여도 스크립트 실행 쪽에는 닿지 않는다.

IBM Plex Sans KR은 Figma에 내장되어 있고 굵기가 Bold/SemiBold/Medium/Regular로 1:1 대응되어 위계가 그대로다. 이 결정으로 글꼴 문제는 닫힌다 — 장표 제작 중 언제든 텍스트를 수정할 수 있다.

**PowerPoint로 옮길 때**는 같은 글꼴을 컴퓨터에 설치해야 한다. Google Fonts에서 무료로 받는다 — 설치하지 않으면 PowerPoint가 기본 글꼴로 바꿔 버린다.

### 마스터의 한계 (미리 알아야 할 것)

- **M3에는 이미지 자리가 없다.** 근거 3칸은 텍스트 전용이다. 07에 `fig-guide-four-designs.png`를 넣으려면 M5를 쓰거나 M3 변형을 새로 만들어야 한다
- **M5의 캡처 자리는 4칸 고정**이다. 2칸이나 3칸이 필요하면 빈 칸을 지우는 게 아니라 M5 원본에서 칸 수를 바꿔야 한다
- **근거는 3칸이 상한**이다. 4칸이 필요하면 메시지가 둘이라는 뜻이므로 장을 쪼갠다
- M2의 진행표시(WHY·WHAT·HOW)는 **막 전환 전용**이다. 마무리 장에 쓰면 아직 진행 중인 것처럼 읽힌다 — 그 장에서는 진행표시를 비우거나 지운다

## 작업 절차

1. `03_장표` 페이지로 이동 — `await figma.setCurrentPageAsync(page)`. 동기 대입(`figma.currentPage = page`)은 동작하지 않는다
2. 장 순서대로 마스터 인스턴스를 생성해 가로로 배치. 간격 200, y 고정
3. 인스턴스 안의 `[자리표시자]` 텍스트만 교체한다
4. **인스턴스의 구조(오토레이아웃·크기·색)는 건드리지 않는다.** 구조를 바꿔야 하면 `02_마스터`의 원본을 고친다. 인스턴스 분리(Detach) 금지
5. 각 장 하단 출처 라벨을 반드시 채운다

## use_figma 함정 — 실제로 부딪힌 것들

이 절을 건너뛰면 같은 자리에서 그대로 막힌다.

```text
글꼴        Pretendard는 이 환경에 없다. loadFontAsync 실패.
            텍스트는 IBM Plex Sans KR로 만든 뒤 setTextStyleIdAsync()로 스타일을 입힌다.
            스타일 적용은 글꼴이 없어도 통과한다.

글꼴 잠금    글꼴이 없는 텍스트는 폭 수정조차 막힌다.
            "Cannot write to node with unloaded font" 가 뜨면 그 글꼴을 await 로드해야 한다.

셀렉터      query() 셀렉터에 한글을 넣으면 에러가 난다.
            [name=대조] 불가 → children.find(c => c.name === '대조') 로 탐색한다.

배경        figma.createAutoLayout() 은 흰 배경이 기본이다.
            내부 컨테이너는 fills = [] 로 비운다. 안 비우면 어두운 배경 장표에 흰 띠가 생긴다.

FILL 순서    layoutSizingHorizontal = 'FILL' 은 appendChild 이후에만 먹는다.
            부모를 나중에 FILL로 바꾸면 자식에 FILL을 다시 걸어야 한다.
            안 하면 텍스트가 옆 칸으로 넘친다.

텍스트 크기  감싸는 텍스트 = textAutoResize 'HEIGHT' + 폭 FILL
            한 줄 텍스트 = textAutoResize 'WIDTH_AND_HEIGHT'
            폭이 고정된 채 글자만 커지면 한 글자씩 세로로 쌓인다.

컴포넌트     createComponentFromNode() 는 노드 id가 바뀐다.
            스크린샷은 변환 전에 찍는다.

롤백        스크립트가 에러로 끝나면 그 스크립트의 변경이 전부 롤백된다.
            작게 쪼개서 실행하고, 매 단계 결과를 확인한다.

기타        색은 0~1 범위. figma.notify() 와 console.log() 는 쓰지 않는다.
```
