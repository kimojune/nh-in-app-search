# Decision Log 인덱스

`docs/decision-log/`의 개별 결정 기록 목록이다. 새 결정 파일을 만들 때마다 이 표에 한 줄 추가한다.

**상태 열에는 아래 네 값만 쓴다.** 자유 서술을 쓰면 "지금 유효한 것만 골라내기"가 불가능해진다. 더 긴 경위는 각 파일의 `- 상태:` 줄과 이 표의 `비고` 열에 적는다.

| 값 | 뜻 |
| --- | --- |
| 확정 | 현행 기준. 그대로 인용할 수 있다 |
| 재검토 | 후속 결정과 충돌해 재정의가 필요하다. 확정으로 인용하지 않는다 |
| 제안 | 에이전트가 쓴 초안이다. `확정`으로 올리는 것은 사용자만 한다 (`WORKSPACE_RULES.md` 참고) |
| 무효 | 기각·대체·취소·폐기됐다. 근거로 쓰지 않는다 |

**상태는 파일명도 제목도 아닌 `- 상태:` 줄에만 둔다.** 상태는 바뀌는 정보다. 파일명에 넣으면 상태가 바뀔 때마다 이름을 고쳐야 하고, 그때마다 그 파일을 가리키는 링크가 전부 깨진다. 파일명과 제목은 결정 주제만 담는다.

`- 상태:` 줄의 첫 토큰은 위 네 값 중 하나여야 한다. 경위는 그 뒤에 ` — `로 이어 붙인다. 첫 토큰이 고정돼 있어야 아래처럼 걸러낼 수 있다.

```
grep -l "^- 상태: 제안" *.md      # 아직 승인 안 된 것만
grep -L "^- 상태: 무효" *.md      # 무효를 뺀 나머지
```
