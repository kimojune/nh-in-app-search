## 먼저 확인할 것 두 가지

**장 수.** 스피커노트의 확정 뼈대는 표지 + 9장, 270초다. 제작 요청서는 13~15장(표지 1 + 간지 3 + 본문 8~10 + 마무리 1)을 요구한다. 간지 3장을 더하면 표지 1 + 간지 3 + 본문 8 + 마무리 1 = 13장이 되어 범위에 들어간다. 아래 목록은 그렇게 짰다.

**시간.** 간지 3장이 늘어난 만큼 270초를 넘는다. 간지는 흘리듯 넘겨 장당 3초로 잡으면 279초이고 5분 상한 안이다. 간지에서 말을 얹으면 넘친다.

이 둘이 발표자 의도와 다르면 간지를 빼고 12장으로 줄인다. 그 경우 각 막의 첫 장(01, 05, 07) 머리에 막 이름만 얹는다.


## 장별 자리표시자 내용

`[대괄호]` 자리에 넣을 글자를 그대로 적는다. 여기 없는 값은 `[대괄호]`로 남긴다. 말할 문장은 이 문서에 넣지 않는다. `발표_스피커노트.md`에 있다.

### 00 표지 · M1

```text
말머리선     (그대로)
직무 라벨    PO · 서비스 기획
한 문장 정의  사용자가 아는 농협은 하나다
```

핵심수치 3칸에 자동 검사 건수를 넣지 않는다. 발표자가 구성을 설명할 수 없는 숫자다. 대신 만든 것 셋을 글자로 넣는다.

```text
실동작 라우터 · 운영 콘솔 · 네 앱 목업
```

표지 아래에 고지 한 줄을 둔다. 자리가 없으면 각주 스타일로.

```text
기획 검증용 목업입니다. 실제 NH농협 서비스가 아닙니다.
```
