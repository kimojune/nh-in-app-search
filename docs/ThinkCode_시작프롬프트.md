- 최종 수정일: 2026-08-21
- 문서 유형: 계속 갱신 (ThinkCode에 붙여넣기 전 최종 확인용 원본)
- 용도: 아래 "프롬프트 본문"을 그대로 복사해 ThinkCode 채팅방에 붙여넣고, `docs/thinkcode_업로드용/` 폴더의 이미지 12장을 하나씩 첨부한 뒤 대화를 시작한다. 이 문서 자체는 제출물이 아니라 착수 준비용 자료다.

## 첨부할 파일 (ThinkCode 채팅방에 프롬프트와 함께 업로드)

`raw/스크린샷/`에는 총 36장이 있지만, 자동완성만 나온 화면·같은 장면의 중복 캡처가 많아 전부 열어서 확인한 뒤 **핵심 9장 + 보조 3장, 총 12장만 선별**했다(나머지 24장은 미사용).

ThinkCode 업로드가 폴더 단위가 아니라 파일 단위(한 장씩)만 가능하므로, `raw/`는 그대로 두고 `docs/thinkcode_업로드용/` 폴더에 **파일명 자체에 화면 번호·역할을 새긴 복사본 12장**을 만들어뒀다. 업로드할 때는 이 폴더의 12개 파일만 하나씩 첨부하면 된다 — 원본 파일명(`Screenshot_...`)을 찾아 대조할 필요 없이, 파일명만 보고도 어떤 화면용인지 바로 알 수 있다.

## 프롬프트 본문 (여기부터 그대로 복사)

NH농협 계열 앱 4개(NH스마트뱅킹, NH콕뱅크, NHPAY, NH올원뱅크)에서 "K-패스카드" 발급을 검색했을 때 앱마다 검색이 실패하는 방식이 다르다는 걸 확인했어. 이 문제를 보여주는 **Before/After 클릭형 목업 프로토타입**을 만들어줘.

### 기술 스펙

- 단일 HTML 파일 하나로 만들어줘 (인라인 CSS + JS, 외부 라이브러리·빌드·서버 없음).
- 화면은 375×812 크기의 폰 프레임 안에서 렌더링하고, 바깥 배경과 구분해줘.
- 상단에 앱 선택 탭 4개(NH스마트뱅킹 / NH콕뱅크 / NHPAY / NH올원뱅크)와 Before/After 토글을 둬서, 조합에 따라 해당 화면으로 바로 전환되게 해줘.
- 새로고침하면 초기 상태로 돌아가도 괜찮아 — 대신 다시 켤 때마다 같은 흐름이 똑같이 재현돼야 해(재현성이 중요한 평가 기준이야).

### 첨부 스크린샷 활용 방법

내가 NH 앱 4개를 실제로 검색해본 화면 캡처 12장을 같이 첨부했어. 파일명 맨 앞의 번호와 이름 자체가 이미 어떤 화면·역할용인지 알려주니(예: `01_NHPAY_Before_카드신청_이응패스혼입.jpg`), 파일명을 그대로 참고해서 아래 대응관계대로 사용해줘 — 각 화면을 만들 때 해당 캡처의 실제 메뉴 라벨·검색 결과 문구·레이아웃을 최대한 그대로 재현해줘(픽셀 단위로 똑같을 필요는 없지만, 텍스트와 구조는 실제와 일치해야 해).

### 만들어야 할 화면 (총 11개 + 공통 컴포넌트 1개)

**1) NHPAY — After만 (Before는 이미 정상)**
- Before: "K-패스카드"/"경기패스카드"/"카드발급" 검색은 정확히 처리되지만, "카드신청" 검색에는 무관한 타지역 카드("이응패스")가 같이 나옴.
- After: "이응패스" 같은 무관 카드만 결과에서 제거. 나머지는 그대로.

**2) NH콕뱅크 — 검색 결과 화면 (Before/After)**
- Before: "K-패스카드"/"경기패스카드" 검색 결과 0건.
- After: "K-패스카드"/"경기패스카드"/"k패스"/"케이패스" 검색 모두 "카드발급"과 같은 결과("금융 > 카드 > NH농협카드 신청")를 보여줌 (동의어 매핑).

**3) NH콕뱅크 — 메뉴 클릭 후 화면 (Before/After)**
- Before: "카드발급" 메뉴 클릭 시 외부 브라우저로 넘어가 NHPAY의 "전체 카드" 목록(79건)으로 이동.
- After: 같은 메뉴 클릭 시 K-패스카드 상세·신청 직전 화면으로 바로 이동(가능하면 외부 브라우저 대신 인앱 화면처럼 표현).

**4) NH올원뱅크 — 검색 결과 화면 (Before/After)**
- Before: "카드신청" 검색에 연금·법원등기·NH K-외국인신용대출 등 무관 결과가 대량으로 나옴. "K-패스카드"/"k패스"는 "NH금융그룹 > NH농협카드" 메뉴로는 안내되지만 상품 자체는 없음.
- After: 무관 결과를 제거하고 "NH금융그룹 > NH농협카드" 메뉴를 검색 결과 상단에 노출.

**5) NH올원뱅크 — 메뉴 클릭 후 화면 (Before/After)**
- Before: "NH금융그룹 > NH농협카드" 클릭 시 일반 NH농협카드 화면(NH Pay 프로모션 배너만 있음)으로 이동, K-패스카드가 아님.
- After: 같은 메뉴 클릭 시 K-패스카드 상세·신청 직전 화면으로 바로 이동.

**6) NH스마트뱅킹 — 검색 결과 화면 (Before/After)**
- Before: "K-패스카드"/"경기패스카드"/"카드발급"/"카드신청" 검색 전부 실패. 보안카드·OTP 같은 무관 결과만 나옴. 이 앱엔 "카드신청" 메뉴 자체가 없음.
- After: 이 앱 안에는 보여줄 정답이 없으므로, 동의어 매핑 대신 **아래 공통 컴포넌트(검색결과 0건 안내 카드)**를 노출.

**7) 공통 컴포넌트 — 검색결과 0건 안내 카드**
- 문구: "찾으시는 카드를 다른 곳에서도 확인해보세요"
- 하위 텍스트: "NH페이(NHPAY)에서 카드 상품을 한눈에 볼 수 있어요"
- 버튼: "NHPAY에서 확인하기" → 클릭 시 아래 8번의 공통 목적지 화면으로 이동
- 이 컴포넌트는 스마트뱅킹 After에서 필수이고, 콕뱅크·올원뱅크의 동의어 매핑으로도 못 잡는 검색어에 대한 안전망으로도 재사용해줘.

**8) 공통 목적지 — NHPAY의 K-패스카드 상세·신청 직전 화면 (1개, 모든 After 경로가 여기로 도착)**

| `k패스`/`케이패스` | 미검증(콕뱅크는 실패 확인) | 기존 메뉴("NH농협카드 신청" / "NH금융그룹 > NH농협카드")로 연결 |
| `카드발급`/`카드신청` | 부분(무관 카드 혼입) | 무관 결과 제거 + 해당 메뉴 상단 노출 |

### KPI 시연 흐름을 화면 안에 넣어줘

Before → After 순서로 토글하면 다음이 눈에 보이게 시연되도록 만들어줘:
1. Before 화면에서 "k패스"/"케이패스" 검색 → 결과 없음
2. After 화면에서 같은 검색어 입력 → 결과 즉시 노출 (스마트뱅킹은 안내 카드로 대체)
3. 이 전환으로 "인앱 검색 성공률 0% → 100%(스마트뱅킹은 크로스앱 안내로 이탈 방지)"와 "잔여 탐색 시간 47초 → 즉시"라는 지표 변화를 화면 위에 짧게 표시해줘(예: 상단 배지나 하단 요약 텍스트).

### 잊지 말아야 할 평가 기준

이 프로토타입은 "동작·완성도(실제 데이터로 제대로 동작)", "성능 지표(수치로 개선 증명)", "재현성(다시 실행해도 같은 결과)"으로 평가받아. 실제 스크린샷 문구를 살리고, 위 KPI 표시를 빠뜨리지 말고, 아무 순서로 눌러도 깨지지 않게 만들어줘.
