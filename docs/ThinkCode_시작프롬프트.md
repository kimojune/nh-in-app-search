# ThinkCode 착수용 시작 프롬프트

- 최종 수정일: 2026-08-22
- 문서 유형: 계속 갱신
- 용도: 현재 안내형 해결안의 제출용 프로토타입을 ThinkCode에서 구현할 때 사용하는 프롬프트

> 2026-08-21 버전의 ‘모든 경로를 K-패스카드 신청 직전 화면으로 자동 이동’ 지시는 폐기했다. 기존 ThinkCode 세션이나 결과물이 그 전제를 사용한다면 현재 프롬프트에 맞게 수정한 뒤 테스트한다.

## 첨부 자료

`docs/thinkcode_업로드용/`의 12장은 NH 앱 4개 검색 상태를 재현하기 위한 참고 자료다. 화면 문구와 검색 결과 구조의 근거로만 사용하고, 실제 NH 서비스처럼 보이게 과장하거나 실제 연동을 구현하지 않는다.

- `01`~`09`: 앱별 대표 검색 결과와 이동 상태
- `10`~`12`: 상품 인덱스·메뉴 매칭 차이를 보여주는 보조 근거

---

## 프롬프트 본문

저빈도 금융 기능을 검색한 사용자가 담당 앱이나 채널을 몰라 외부 포털에서 다시 검색하는 문제를 다루는 클릭형 웹 프로토타입을 만들어줘. K-패스카드와 NH 앱 4개는 첫 적용 사례일 뿐이고, 핵심 해결안은 금융사가 기존 검색 위에 적용할 수 있는 `검색어 → 기능·카테고리 → 담당 채널과 역할 안내` 구조야.

### 반드시 지킬 범위

- 정확한 상품 화면으로 자동 이동시키지 않는다.
- 실제 NH 앱·백엔드·거래·로그인·딥링크를 구현하지 않는다.
- 한 기능에 처리 채널이 여러 개일 수 있다.
- 각 채널을 `완료`, `경유`, `안내` 중 하나로 표시하고 다음 행동을 설명한다.
- 검색 결과가 0건일 때뿐 아니라 결과가 있어도 담당 채널이나 다음 행동이 불명확하면 안내를 보여준다.
- NH 화면은 사례 재현용이며 결과물을 실제 NH 기능으로 표현하지 않는다.

### 기술 스펙

- 단일 HTML 파일(인라인 CSS·JS, 외부 라이브러리·빌드·서버 없음)
- 375×812 폰 프레임 중심의 반응형 화면
- 새로고침 후에도 같은 흐름을 재현할 수 있는 고정 샘플 데이터
- 키보드 조작과 명확한 포커스 상태를 포함한 기본 접근성

### 사용자 흐름

1. 사용자가 금융 기능을 자유 검색한다.
2. 검색어를 승인된 기능·카테고리에 매핑한다.
3. 가능한 담당 채널을 복수로 보여준다.
4. 각 채널의 역할과 다음 행동을 표시한다.
5. 참가자가 하나를 선택하면 선택한 채널·역할·소요시간·검색어 재입력 횟수를 결과 요약에 보여준다.

K-패스카드 예시 결과:

- `NHPAY · 완료` — 카드 상품을 확인하고 신청할 수 있음
- `모바일웹 · 완료` — 앱 설치 없이 상품을 확인하고 신청할 수 있음
- `올원뱅크 · 안내` — 담당 채널 정보를 확인할 수 있음

채널 선택 이후에는 실제 앱이나 신청 화면으로 이동하지 말고, 참가자가 이해한 다음 행동을 선택하거나 짧게 답하게 해줘.

### NH 앱 4개 사례 화면

- NHPAY: 관련 검색이 비교적 정확한 상태. 정확한 결과가 있으면 불필요한 안내를 중복 노출하지 않는다.
- NH콕뱅크: K-패스 관련 표현을 기능에 매핑하고, 기존 일반 카드 메뉴와 함께 실제 처리 채널·역할을 안내한다.
- NH올원뱅크: 관련 메뉴가 있어도 처리 경로가 불명확한 상태를 보여주고 담당 채널 안내를 덧붙인다.
- NH스마트뱅킹: 관련 상품 결과가 없을 때 0건 안내와 함께 처리 가능한 채널을 보여준다.

첨부 스크린샷의 실제 관찰 내용은 Before 설명 근거로 사용하되, After에서 기존 메뉴 클릭 목적지를 K-패스카드 상세 화면으로 바꾸지 않는다.

### 운영자 흐름

별도 탭이나 시작 화면에 최소한의 운영 흐름을 재현해줘.

1. 계열사·담당 부서가 사용자 표현, 기능, 담당 채널, 역할, 다음 행동을 등록한다.
2. 중앙 관리자가 등록 내용을 검토해 승인 또는 반려한다.
3. 승인된 매핑만 사용자 검색 결과에 배포된다.

실제 권한 시스템이나 규칙 엔진은 필요 없고, 샘플 데이터 한 건이 등록→승인→배포되는 상태 변화만 재현하면 된다.

### 테스트 결과 화면

다음을 보여줘.

- 외부 검색·진행자 도움 없이 올바른 채널과 다음 행동을 결정했는지
- 선택 채널과 역할
- 결정까지 걸린 시간
- 검색어 재입력 횟수
- 역할 오해 여부

`검색 성공률 0% → 100%`, `47초 → 즉시`, 신청 전환율 개선처럼 아직 검증하지 않은 수치를 표시하지 않는다.

### 품질 기준

- 어떤 순서로 눌러도 화면 상태가 깨지지 않는다.
- 복수 채널과 역할 차이가 한눈에 구분된다.
- 안내를 신청 완료나 자동 이동으로 오해하게 만들지 않는다.
- 등록·승인·배포와 사용자 검색 흐름이 하나의 콘셉트로 연결된다.
- 프로토타입임을 화면에 명시한다.
